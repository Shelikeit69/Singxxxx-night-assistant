# SINGXXXX 夜间客服机器人（方案 v0.5）

> Toni 为面试准备的方案和流程原型，2026-10-06。
> 公司名用 SINGXXXX 代替，这里不是该公司的官方渠道。演示里的产品名和价格是示例，库存数字是编的。

## 要解决的问题

晚上和周日有客户在 WhatsApp 上问，要到第二天才有人回。问题大多很具体：我家的门能不能装、哪款合适、有没有货。这些都得按型号和门型来答。

## 方案

现有的 WhatsApp 号码接上云端 AI。晚上由它回答常见问题、收集安装信息，第二天早上同事拿到的是一张整理好的工单。夜间版大约 4 周能上线，接库存大约要 8 周。每月运行成本估计在 US$68-93（用 DeepSeek）或 US$77-139（用 Claude），人工不算在内。

## 怎么看演示

- 在线：<https://shelikeit69.github.io/Singxxxx-night-assistant/>。想直接看中文，在网址后面加 `?lang=zh`，或者点右上角的「中文」。
